Each subclass supports specific filters. You can get a full list for a subclass
using the .show_categories() class method.

Example for Services:
>>> from craigslist import CraigslistServices
>>> CraigslistServices.show_categories()

Output:
CraigslistServices categories:
* aos = automotive services
* bts = beauty services
* cms = cell phone / mobile services
* cps = computer services
* crs = creative services
* cys = cycle services
... (full list in the PDF)

To use a category, pass the `category` parameter when initializing:
cl = CraigslistHousing(site='sfbay', area='sfc', category='roo')   # 'roo' = rooms

================================================================================
5. AVAILABLE FILTERS FOR EACH SUBCLASS
================================================================================

General filters (apply to most subclasses):
- `max_price` : integer
- `min_price` : integer
- `search_distance` : integer (miles)
- `postal` : string (postal code for location‑based search)
- `has_image` : boolean (True/False)
- `auto_paint` : for vehicles (e.g., 'black', 'blue', 'brown', 'green')
- `auto_size` : 'compact', 'full‑size', 'mid‑size'
- `auto_title_status` : 'clean', 'salvage', 'rebuilt'
- `auto_transmission` : 'manual', 'automatic', 'other'
- `auto_bodytype` : 'bus', 'convertible', 'coupe', 'sedan', etc.

Jobs‑specific filters:
- `is_internship` : boolean
- `telecommuting` : boolean
- `contract` : boolean

Housing‑specific filters:
- `bedrooms` : integer (e.g., 1, 2, 3)
- `bathrooms` : float (e.g., 1.5)
- `housing_type` : 'apt', 'condo', 'house', 'duplex', etc.
- `laundry` : 'w/d in unit', 'w/d hookups', 'no laundry'
- `parking` : 'carport', 'detached', 'attached', 'off‑street'

Events‑specific filters:
- `free` : boolean (free food / free entry)

6.1 HOUSING – Look for a room in San Francisco (maximum price $1200)
-------------------------------------------------------------------------------
from craigslist import CraigslistHousing

cl_h = CraigslistHousing(
    site='sfbay',
    area='sfc',               # San Francisco city
    filters={'max_price': 1200}
)

# Get approximate result count
print(cl_h.get_results_approx_count())   # e.g., 992

# Iterate over results (newest first, geotag included)
for result in cl_h.get_results(sort_by='newest', geotag=True, limit=10):
    print(result)

# Sample output:

7. API REFERENCE – METHODS & PARAMETERS
================================================================================

Constructor for any subclass:
    ClassName(site, area=None, category=None, filters=None)

Parameters:
    site (str)      : required, e.g., 'sfbay', 'newyork', 'london'
    area (str)      : optional, e.g., 'sfc', 'mnh', 'sby'
    category (str)  : optional, e.g., 'roo', 'cps', 'eng' (engineering jobs)
    filters (dict)  : optional, keys as described in section 5

Methods:
    1. .get_results(sort_by=None, limit=None, geotag=False)
        - sort_by : 'newest' or None (default ordering)
        - limit   : integer, maximum number of results (Craigslist caps at 3000)
        - geotag  : boolean, if True adds (lat, lng) tuple to each result
        Returns a generator that yields result dicts.

    2. .get_results_approx_count()
        - Returns an approximate number of total results for the query.

    3. .show_categories() – class method, prints all categories for the subclass.

Result dictionary keys:
    - id         : string (posting ID)
    - name       : string (title)
    - url        : string (full URL)
    - datetime   : string (posting time, format varies)
    - price      : string or None
    - where      : string (location text)
    - has_image  : bool
    - has_map    : bool
    - geotag     : (float, float) tuple or None

9. IMPORTANT LIMITATIONS & BEST PRACTICES FOR YOUR APP
================================================================================

- **Result cap**: Craigslist never returns more than 3000 results per query.
- **No official API**: This library scrapes the HTML. It may break if Craigslist
  changes its markup.
- **Rate limiting**: Do NOT send requests too quickly. Add delays between calls:
    import time
    time.sleep(1)   # minimum 1 second between requests
- **Ethical use**: Follow Craigslist's Terms of Use. Consider caching results
  to avoid unnecessary repeated scraping.
- **Error handling**: Always wrap requests in try/except blocks. Network issues
  or CAPTCHA pages may occur.
- **User‑Agent**: The library uses a default User‑Agent. For production,
  consider rotating User‑Agents to reduce fingerprinting.

Example robust integration snippet:
------------------------------------------------
from craigslist import CraigslistHousing
import time

def safe_scrape(site, area, filters, max_retries=3):
    for attempt in range(max_retries):
        try:
            cl = CraigslistHousing(site=site, area=area, filters=filters)
            results = list(cl.get_results(limit=50, geotag=True))
            time.sleep(1.5)
            return results
        except Exception as e:
            print(f"Attempt {attempt+1} failed: {e}")
            time.sleep(5)
    return []
